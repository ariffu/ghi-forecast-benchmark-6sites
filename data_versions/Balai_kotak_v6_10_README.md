# Balai_kotak_v6_10 — statistik kotak CLP untuk Manuskrip V6 (tahap 28)

Dibangun 2026-11-08 oleh `solardata_new_v2/paper_v2_clpbanten/113_kotak_chips/z3_bangun_kotak.py`. Beku, hanya-baca.

Sumber nilai: CSV kotak 11×11 piksel (Kalbar 10×11), buffer 30 km, di `6lokasi_output_chips.zip`, sama dengan `clp_cot` V6.10 (CLOT_mean = clp_cot persis). Kotak dan waktu diverifikasi piksel demi piksel dengan `chips_supplement_6.zip` (tahap 113 Z1/Z2). Nilai chip tidak dipakai karena tersimpan sebagai bilangan bulat terpotong.

Konvensi: grid 10 menit WIB V6.10, t = T + 10; kosong bila tidak ada berkas; statistik COT/CTH kosong bila kotak tanpa piksel berawan. `clps_cloud_frac` = `clp_cloud_frac` V6.10 (prediktor ke-44); untuk uji tahap 28 V6 dipakai enam fitur lain.
